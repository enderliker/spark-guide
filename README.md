# SparkWiki

Documentation website for the Spark programming language, styled after the
VuePress-era design of [discordjs.guide/legacy](https://discordjs.guide/legacy).

- 35 content pages: getting started, language guide, standard library,
  networking, tooling, internals and an appendix.
- Self-contained static site generated by a Python script with no third-party
  dependencies.
- Custom Markdown renderer, syntax highlighter, client-side search, table of
  contents with scrollspy, previous/next navigation and a dark/light theme.

## Build

```bash
python3 build.py
```

The output is written to `dist/`. The build also generates
`dist/assets/js/search-index.js` and reports missing content files, broken
internal links and unresolved cross-page references.

## Preview

```bash
python3 -m http.server -d dist 8000
```

Then open <http://localhost:8000/>.

## Deploy

The site is hosted on Vercel at <https://spark-guide.vercel.app/> and deploys
automatically from `main`. Vercel runs `python3 build.py` and serves `dist/`; no
build output is committed. Open a pull request to get a preview URL before
merging.

```bash
git push origin main
```

## Layout

```
build.py                     site generator and navigation config
content/                     one Markdown file per page
  getting-started/           introduction, installation, first program
  guide/                     the language, from variables to coroutines
  stdlib/                    text, collections, math, files and system
  networking/                sockets, TLS, HTTP client and server, WebSockets
  tooling/                   CLI, debugger, formatter/linter, bytecode
  internals/                 architecture, VM, GC, limits and benchmarks
  appendix/                  example gallery and roadmap
assets/css/style.css         the theme
assets/js/app.js             theme toggle, search, TOC, sidebar, copy buttons
assets/logo/                 the Spark icon and wordmark (SVG)
dist/                        generated site (rebuild after changing content)
```

## Brand

`spark-icon.svg` and `spark-logo.svg` in `assets/logo` are the language's logo.
The icon is used in the navbar and as the favicon; the full lockup heads the
home page and is inlined so its wordmark can follow the light or dark theme.

The logo files are not MIT licensed; see `assets/logo/LICENSE`.

| Token | Value | Use |

| Ember | `#ff8a2b` | Accent, links, primary buttons |
| Gold | `#ffd36b` | Code highlights, secondary emphasis |
| Flame | `#e8412a` | Gradient end, danger blocks |
| Cream | `#fff1c9` | Wordmark on dark, warm text |

## Writing content

Use standard GitHub-flavored Markdown plus the containers the generator
understands:

```markdown
::: tip
A useful aside.
:::
```

Supported container kinds are `note`, `tip`, `warning` and `danger`; the title
is optional. Link between pages with `@section/page`, for example
`[Maps](@guide/maps)`. The build flags references that do not resolve.

Code fences must name a language: `spark`, `bash`, `text`, `json`, `c`, `csharp`
or an empty fence for plain text.
